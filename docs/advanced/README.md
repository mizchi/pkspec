# Advanced pkspec usage

These notes cover workflows that are useful once a project already has
stable Goals, Scenarios, and Test links. Keep first-time onboarding in
`docs/notes/authoring-guide.md`; use this directory for planning,
review, and large-project conventions.

- [`goals-and-milestones.md`](./goals-and-milestones.md) — Goal progress
  calculation methods, Milestone rollups, and how to choose between
  scenario-count and severity-weighted reporting.
- [`recipes/launch-readiness.md`](./recipes/launch-readiness.md) — a
  larger copyable recipe for launch planning with multiple Goals,
  weighted progress, Milestones, linked tests, and review commands.
